# AgentLens SDK

Python SDK for integrating AgentLens observability into AI agents.

## Installation

```bash
pip install -e .
```

## Development Installation

```bash
pip install -e ".[dev]"
```

## Usage

*SDK usage documentation will be added in Phase 2*

## Testing

```bash
pytest
```

## Features (Planned)

- Event capture decorators
- Automatic trace context propagation
- LLM call tracking
- Tool execution tracking
- Error capture
- Custom metadata attachment

## Requirements

- Python 3.11+
- httpx
- pydantic
